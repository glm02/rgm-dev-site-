# Modèles d'email Supabase

À coller dans Supabase → Authentication → Email Templates.

| Modèle Supabase | Fichier | Objet (Subject) |
|---|---|---|
| Confirm sign up | `confirmation-inscription.html` | Confirmez votre adresse email |
| Invite user | `invitation.html` | Votre espace client RGM Dev vous attend |
| Magic link or OTP | `lien-magique.html` | Votre lien de connexion RGM Dev |
| Change email address | `changement-email.html` | Confirmez votre nouvelle adresse email |
| Reset password | `reinitialisation-mot-de-passe.html` | Choisissez un nouveau mot de passe |
| Reauthentication | `reauthentification.html` | Votre code de vérification RGM Dev |
